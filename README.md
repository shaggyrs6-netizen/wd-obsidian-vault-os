# WD Obsidian Vault OS — alpha

A small, local Obsidian starter vault for finding your way back to a project after an interruption. Built from Lee's experience of working with Parkinson's and intended for anyone whose attention or energy varies. The notes are plain Markdown on your computer; AI help is optional.

**This is an alpha.** Start with fictional answers in a separate test folder. The package does not include Obsidian, connect accounts, start scheduled notes or publish anything. It is not a medical tool.

## Download and start

Use the latest pre-release assets on the [Releases page](https://github.com/shaggyrs6-netizen/wd-obsidian-vault-os/releases):

- `WD Obsidian Vault OS 0.3.1 alpha.zip` — the test vault and offline start page.
- `TESTER-INSTRUCTIONS.pdf` — a one-page guide for Windows, macOS and Linux.
- `SHA256SUMS.txt` — checksums for both downloads.

Create a new folder in Documents. Extract the ZIP there, then double-click `START HERE.html`. The inner vault folder is technically named `WD Vault OS` in this version; keep it separate from any existing vault. Open that inner folder in [Obsidian](https://obsidian.md/download) after the first saved result.

## What has been checked

The release ZIP is reconstructed from the pinned 0.3.0 candidate with ten declared documentation changes. Automated smoke checks run on Linux, Windows and macOS for extraction, package integrity, fictional setup, pause/resume and four starter notes. Those checks do not prove the Obsidian interface or AI desktop connections work for every person; that is part of the alpha test.

The original Wired Differently material is supplied for personal alpha evaluation; no separate open-source licence is granted here. The optional [Prism theme](https://github.com/damiankorcz/Prism-Theme) retains its MIT licence, and embedded font notices are included in the ZIP. See the package's `System/Use and provenance.md` and `System/Third-party credits.md`.
